# NOSSA PADEL — Brand Kit & Style Guide

A complete, self-contained HTML reference for the **NOSSA PADEL** visual identity system.

## Contents

| Section | Description |
|---|---|
| 01 · Brand Foundation | Mission, name meaning, positioning, heritage, promise |
| 02 · Colour Palette | Core palette, neutral system, product accent colours |
| 03 · Typography | Space Grotesk + Space Mono type specimens and scale |
| 04 · Logo System | Logo lockups, icon mark, anatomy, usage rules |
| 05 · UI Components | Navigation, buttons, product tiles, spacing scale |
| 06 · Photography | Imagery direction — cinematic, neutral studio, lifestyle |
| 07 · Voice & Tone | Brand pillars, copy examples, do/don't guide |
| 08 · Product Hierarchy | NOSSA CORE, BASE, HYBRID range overview |

## Usage

Open `nossa-padel-brand-kit.html` directly in any modern browser. No build step required. Assets are referenced from a local `assets/` directory.

## Brand Snapshot

- **Typefaces:** Space Grotesk (display/body) · Space Mono (labels/metadata)
- **Core Colours:** NOSSA Black `#000000` · Off-White `#F5F4F0` · Ink `#1A1916`
- **Accent Colours:** Velocity Blue `#1A4AE8` · Court Green `#1C4A2E`
- **Version:** 1.0 · 2026
